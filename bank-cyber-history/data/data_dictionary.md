# Data Dictionary — `incidents.csv` / `incidents.json`

The data is generated by `analysis/build.py` from `analysis/incidents_source.py`. Edit the source file, never the CSV.

| Field | Type | Description |
|---|---|---|
| id | string | `INC-YYYY-NNN`, a unique identifier |
| name | string | Short incident name |
| start / end | string | Event start and end (ISO date or partial; free-text qualifiers allowed) |
| detection | string | Date of detection by the victim, where known |
| disclosure | string | First public disclosure |
| country / region | string | Victim country; region ∈ {North America, Europe, Asia-Pacific, South Asia, Middle East, Latin America, Global} |
| org | string | Affected organisation(s) |
| org_type | string | Bank, Broker-dealer, Processor, Vendor, Market infrastructure, Crypto exchange, Card issuer, Regulator, Other financial, Government financial infrastructure |
| attacker | string | Actor as publicly named |
| attribution | string | Attribution confidence and its basis |
| motive | string | Financial / Espionage / Disruption / Extortion / Political signalling / None |
| category | string | Attack category (free text) |
| vector | string | Publicly known initial compromise vector |
| sequence | string | High-level attacker activity (conceptual) |
| systems | string | Compromised systems |
| process | string | Financial process affected |
| stolen_usd_m | number/null | Confirmed or best-reported **net** direct loss, USD millions (approx.). null = undisclosed |
| stolen_orig | string | Loss as reported in the original currency, with qualifiers |
| attempted_usd_m / attempted_orig | number/null, string | Attempted amount |
| recovered_usd_m | number/null | Amount recovered, USD m |
| downtime | string | Operational downtime |
| customers | string | Customers affected |
| settlement | string | Payment and settlement effects |
| regulatory | string | Regulatory response |
| fs_impact | string | Financial-statement impact |
| legal | string | Legal and enforcement outcomes |
| root_causes / failed / worked | string | Root causes; controls that failed; controls that worked |
| lessons / unresolved | string | Lessons learned; open questions |
| status | enum | CONFIRMED, REPORTED, ALLEGED, DISPUTED, INFERRED, UNKNOWN |
| evidence | int 1–5 | Evidence quality score (see methodology.md) |
| is_cyberattack | bool | False for non-malicious comparators (CrowdStrike 2024, Shinkin 2026) |
| state_link | enum | confirmed-gov, suspected, claimed, none-known |
| verification | string | "web-verified 2026-11-07…" or "canonical (training knowledge)" |
| sources | list (CSV: " \| " separated) | Primary and corroborating URLs |
| year | int | Derived from `start` (falls back to `disclosure`) |
| family | string | Derived attack family (keyword rules) |
| entry | string | Derived entry-point class (keyword rules) |
| period | string | Era A–F |
| motive_group | string | Derived motive class |
| inst_class | string | Bank / card issuer; Vendor / processor; Market / public financial infrastructure; Crypto exchange; Broker-dealer / other financial |

**Empty strings** mean the field was not populated for compact records (marked "See sources") or the value is unknown. "Not publicly disclosed" means we looked for it and it has not been disclosed.

## `source_register.csv`
url, domain, source_type (Primary / Secondary journalism / Security-vendor / Encyclopedic), incidents (IDs), http_check_2026_11_07, note.
