# Chart notes

All charts generated by `analysis/build.py` from `data/incidents.csv` (61 records, curated sample).

**Denominator limitation:** the database is a purposive sample of materially significant, publicly documented incidents. Counts by year, region or category describe the *sample*, not the world, and must not be read as trends in incidence. Recent years are over-sampled because the brief prioritised 2025-26.

| Chart | Method | Main caveat |
|---|---|---|
| 01 timeline | one point per record, colour by family | selection bias |
| 02 region | count by `region` | English-language/US-source bias |
| 03 category/period | keyword family of `category` | classification is analyst judgement |
| 04 losses | `stolen_usd_m` log scale | many losses undisclosed; FX approximate |
| 05 motives | keyword of `motive` | motives often inferred |
| 06 institution | `org_type` grouped | vendor incidents may be under-disclosed |
| 07 state link | `state_link` | 'suspected' is not attribution |
| 08 entry point | keyword of `vector` | most victims do not disclose vector |
| 09 network | conceptual | illustrative only |
| 10 flows | rule-based mapping | simplification |
| 11 transmission | conceptual | no empirical full-chain case |
| 12 dashboard | four case records | see global_case_studies.md |

For population-level statistics use IMF WP/26/62 (Khiaonarong & Zheng, 2026), EBA Risk Assessment Questionnaire, FS-ISAC reports - each with their own coverage limits (see sources.md).
